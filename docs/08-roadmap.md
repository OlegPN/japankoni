# Этап 8. План развития KONI (соло + AI)

> Сетап: ты как PM/QA/дизайнер + Claude Code как разработчик + другие AI для контента и медиа. Без найма людей, без студийной записи, без юристов на старте.

---

## 0. Якорь продукта — фишка

**Anime Loop (упрощённый)** — «звуковая сцена», не видео.

```
услышал реплику → не понял слово →
тапнул по субтитру → слово в SRS →
вернулся к сцене → теперь слышишь
```

Что в сцене:
- 1 AI-иллюстрация (Midjourney/DALL-E/Imagen)
- 10–20 сек AI-озвучки (ElevenLabs JP voices)
- JSON субтитров с тапаемыми словами
- Без видео-монтажа, без живых сэйю

Если позже зайдёт — добавим короткие AI-видео (Sora/Veo/Kling). На старте не нужно.

## 3. Вехи (соло + AI)

### M1 — Фишка живёт на 1 сцене
**Срок: 2 недели.**

1. Anime Loop player: still + аудио + тапаемые субтитры
2. 1 готовая сцена (картинка + ElevenLabs озвучка + JSON субтитров)
3. Расширение SRS: тип карты `vocab:X` (слово → значение, значение → слово, listen → write)
4. 30 базовых N5-слов из этой сцены + соседних тем
5. Катакана 46 знаков (Claude генерит мнемоники, ты валидируешь по jisho)
6. Чтения кандзи в SRS для уже выученных 20

**Что НЕ делаем:** Supabase, AI Talk, монетизацию.
**Гейт:** ты сам прошёл сценарий с нуля и понял ≥70% слов сцены за неделю.

### M2 — Контент N5 + AI Talk текстом
**Срок: 4 недели.**

1. **Anime Loop ×8** — 8 сцен на 8 ключевых грамматических тем
2. **Грамматика +12 паттернов** (итого 15) — Claude генерит черновики, ты редактируешь
3. **Кандзи до 100** (были 20) — Claude + Jisho для чтений и значений
4. **Vocab до 300 слов** N5 — берём из публичных Anki-колод, фильтруем
5. **AI Talk текстом** — Claude API с системным промптом «ты Кони, знаешь что выучил пользователь, говори простыми JP-фразами с переводом»
6. **Listening-карты** — TTS из ElevenLabs кешируем в Supabase storage

**Что НЕ делаем:** голосовой Talk (STT), pitch.
**Гейт:** 5 друзей-тестеров проходят 7 дней без жалоб «ничего не понятно».

### M3 — Запуск
**Срок: 2 недели + ожидание сторов.**

1. Supabase миграция (если ещё не сделана) — данные не должны теряться
2. **Free / Paid** — упрощённые тарифы:
   - Free: кана + катакана + 30 кандзи + 5 паттернов + 3 сцены + 5 мин Talk/день
   - Paid (~500₽/мес): всё остальное + безлимит Talk
3. Биллинг — самое простое:
   - Веб: Boosty или ЮKassa (РФ-аудитория)
   - Android: Google Play Billing
   - iOS — пока пропускаем
4. RuStore + Google Play submit
5. Лендинг (один экран, скриншоты, кнопка «попробовать»)

**Гейт:** есть первые 10 платящих.

### M4 — Vocab N5 целиком + Anime Loop scaling
**Срок: 4 недели.**

1. Vocab до 800 слов (полный N5)
2. Грамматика до 50 паттернов (полный N5)
3. Anime Loop: 15–20 сцен
4. Onboarding-выбор аниме («какой тайтл хочешь понять?») → подмешиваем его лексику
5. Виральные share-карточки «понимаю X% из <тайтл>» для TikTok/Reels

### v1.1 — Polishing
**Когда есть силы.**

1. Голосовой AI Talk: Whisper STT + ElevenLabs TTS
2. iOS App Store
3. Прорисовка хираганы (canvas)
4. EN-интерфейс (Claude переводит весь UI)

### v1.2 — Pitch и N4
**Когда есть аудитория.**

1. Pitch accent визуализация (CREPE через ONNX в браузере)
2. N4: +50 паттернов, +200 кандзи, +1500 слов
3. AI-видео-сцены (Kling/Veo)

## 4. Где AI справится сам, где нужен ты

| Задача | Кто делает | Что проверяешь ты |
|---|---|---|
| Код, миграции, логика | Claude Code | работает ли при ручном тесте |
| Мнемоники RU | Claude | звучит ли естественно по-русски |
| Грамматические разборы | Claude | сверка с Tae Kim / японским учебником |
| Переводы примеров | Claude → DeepL → Jisho | три источника согласны? |
| Озвучка | ElevenLabs JP | слушаешь, отбрасываешь странные |
| Иллюстрации | Midjourney | принимаешь/перегенерируешь |
| Vocab-списки | публичные Anki | фильтруешь под темы сцен |
| Дизайн UI | мокапы уже есть + Claude по ним | визуальная проверка |
| Тест на реальных людях | 3–5 друзей | сам наблюдаешь |

## 5. Риски этого упрощённого подхода

| Риск | Митигация |
|---|---|
| AI-озвучка хуже нативной | Берём только ElevenLabs JP voices с высоким рейтингом, отбираем вручную; в v1.2 — заменим на нативные записи |
| Мнемоники могут быть кринж | Ты как RU-носитель ставишь финальный фильтр; правишь те, что не зашли |
| Ошибки в грамматических объяснениях | Перекрёстная проверка Claude vs учебник Tae Kim / Genki; держим список ошибок и фиксим по фидбэку |
| Стиль AI-картинок «слишком AI» | Один консистентный промпт-стиль для всех сцен; если не зайдёт — сменим на одного художника-фрилансера в M3 |
| Capacitor iOS требует Mac + $99/год | iOS откладываем до v1.1 — Android покрывает РФ-сегмент A |
| Выгорание соло-разработчика | Жёсткие гейты scope: M1 = 2 нед, не 4. Откатываем фичи, не двигаем срок |
